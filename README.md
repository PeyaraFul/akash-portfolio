## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/PeyaraFul/your-portfolio-repo.git
```

### Navigate to Project Directory

```bash
cd your-portfolio-repo
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
